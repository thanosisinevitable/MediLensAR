# Decisions

- **Native Android instead of Unity.** The deliverable is an Android camera app with AR annotations and conventional personal-plan screens. ARCore provides the required spatial APIs without a game-engine runtime. Android Studio works on Windows/macOS. The PDF's Unity implementation suggestion is superseded by the user's preference for a native Android app.
- **Java 17 source and platform views.** Two meaningful runtime dependencies (ARCore and bundled ML Kit); no unnecessary Kotlin/Compose/Room/JNI boundary. The pure domain code can be compiled and tested with the available Java runtime. Java is a native Android language; the visual controls are not a webview.
- **ARCore owns camera frames.** Do not bind CameraX to the same camera in parallel. CPU images come from the ARCore frame, preserving geometry correspondence. The app is AR-required, with a clear unsupported-device state.
- **Conservative OCR-block baseline.** A trained detector was not supplied. Do not call OCR boxes medication-package detections, invent a trained model, or borrow ingredient text across nearby packs. The baseline sacrifices recall and awaits a validated detector.
- **Exact evidence before confidence.** Brand, ingredients, units, strengths, variant restrictions and repeated observations are required. No fuzzy nearest match becomes a medication identity. Confidence is a rule category, not a calibrated probability.
- **Local canonical ingredients.** Duplicate intersections and deterministic interaction pairs use IDs, not display labels. No DDI row means NO DATA. Clinical severity and identification confidence remain separate fields.
- **Small documented subset.** Retain traceable facts from three official sources. `SOURCE_CHECKED_NOT_CLINICALLY_REVIEWED` describes the actual review level. Do not inflate coverage toward the proposed 250 medicines.
- **Depth-only attachment.** Only ARCore DepthPoint hits create package-proximate anchors. A plane behind a package is insufficient evidence of package depth. Projected anchors are approximate point annotations, not rigid object pose estimates; screen fallback is labeled.
- **Short-lived evidence.** Expire labels promptly, invalidate asynchronous results after lifecycle changes, reject large camera motion during OCR, and recheck identities. Track identity is not an anchor or a permanent medicine identity.
- **User-entered occurrence times.** No schedule inference. Store instants and original zones. Reject skipped/repeated DST local times instead of silently choosing one.
- **Encryption and privacy.** Android Keystore AES-GCM encrypts medication/time/event payloads; SQLite stores random occurrence IDs. App backup and explicit backup-domain transfer are disabled. System diagnostics contain stable error codes, not raw OCR/medicine content.
- **Reproducible dependency setup.** AGP 8.9.2, Gradle 8.11.1, SDK 35, ARCore 1.48.0, ML Kit 16.0.1. Verify official Gradle JAR/distribution checksums. No unverified bootstrap binary is shipped.
