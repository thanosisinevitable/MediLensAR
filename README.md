MediLens is a native Android prototype that reads medicine packaging with the camera and displays information in an augmented reality view. Built with Java, ARCore, ML Kit text recognition and a local SQLite database, it includes medicine identification, limited interaction and duplicate-ingredient checks, and a medication schedule. Open the project in Android Studio and follow [START_HERE.md](START_HERE.md) to build and run it. This is a research prototype, not a clinically validated medical app.
